# Obsidian Writing

Use this skill when the user wants writing that will live in Obsidian and should read cleanly on the page.

## Priorities

- Make the text readable, structured, and calm.
- Prefer short sections, clear headings, and strong paragraph rhythm.
- Preserve Obsidian-friendly Markdown.
- Keep formatting elegant but restrained.

## Writing Rules

- Start with the point, then expand.
- Prefer concrete nouns and verbs.
- Remove filler, repetition, and vague transitions.
- Break dense text into short paragraphs.
- Use lists only when they improve scanability.
- Keep bullet items parallel and compact.

## Obsidian Formatting

- Use `#` headings sparingly and consistently.
- Use `> [!note]`, `> [!tip]`, or similar callouts only when they add real structure.
- Use wikilinks when the vault convention expects them.
- Use tables only for comparisons, checklists, or compact reference data.
- Use code blocks for commands, examples, or source snippets.
- Avoid decorative formatting that does not improve reading.

## Visual Style

- Favor generous spacing over crowded blocks.
- Keep line structure varied but orderly.
- Use bold text only for emphasis that matters.
- Avoid overusing em dashes, emoji, and ornamental symbols.
- Make headings descriptive, not clever.

## When Rewriting

- Preserve meaning first.
- Improve flow, then tighten wording.
- If the user asks for a more polished or aesthetic result, make the layout cleaner before adding more content.
