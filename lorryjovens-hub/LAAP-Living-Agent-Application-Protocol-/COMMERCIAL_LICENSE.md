## 1. 协议范围

本《LAAP 商业授权协议》（以下简称"本协议"）规定被授权方（以下简称"您"或"被授权方"）在获得 LAAP 项目维护者书面授权后，使用、修改、分发 LAAP 商业版代码及相关服务（以下简称"商业版"）的权利与义务。

LAAP 社区版代码以分层许可发布，详见 [LICENSING.md](LICENSING.md)。本协议适用于以下情形：

1. 将 BSL 1.1 层级的核心引擎（`laap/`、`aris_brain/`）用于生产环境；
2. 使用 Rust 原生 PSI Core（`core/` 高性能闭源二进制）；
3. 使用企业版功能、闭源插件、云服务；
4. 本协议明确授权的其他内容。

未获得商业授权前，上述使用行为均被禁止。

---

## 2. 定义

- **LAAP**: Living Agent Application Protocol，数字生命应用协议。
- **Aris**: LAAP 框架下的默认数字生命体实现。
- **Compiled AI**: LAAP 项目提出的"编译式 AI"范式及相关方法论。
- **社区版**: 以分层许可公开发布的 LAAP 参考实现代码，其中核心引擎采用 BSL 1.1（非生产使用免费）。
- **商业版**: 由权利方单独提供、受本协议约束的闭源代码、功能模块、云服务及配套资料，以及 BSL 1.1 层级在生产环境中的使用授权。
- **BSL 1.1 层级**: 指适用 Business Source License 1.1 的 `laap/`、`aris_brain/` 等核心引擎代码。
- **Rust PSI Core**: 高性能原生认知引擎二进制，以闭源商业授权形式提供。
- **物种库（Species Library）**: LAAP 框架中用于零 token 代码生成的模板化能力集合。
- **被授权方**: 与权利方签署本协议并获得商业授权的自然人、法人或其他组织。

## 3. 授权内容

在您遵守本协议所有条款的前提下，权利方授予您：

1. **使用许可**: 在授权范围内使用商业版及相关服务的权利；
2. **修改许可**: 为自身业务需要修改商业版的权利；
3. **分发许可**: 在授权范围内将商业版作为您产品或服务的一部分进行分发的权利；
4. **技术支持**: 根据您购买的授权级别获得相应技术支持的权利。

## 4. 限制

未经权利方书面同意，您不得：

1. 将商业版或 BSL 1.1 层级用于授权范围之外的场景；
2. 对 Rust PSI Core 进行反向工程、反编译或反汇编；
3. 将商业版转授权、出租、出借或出售给第三方；
4. 移除或修改任何版权声明、许可声明或商标标识；
5. 使用 LAAP、Aris 等商标作为您的产品或服务品牌。
