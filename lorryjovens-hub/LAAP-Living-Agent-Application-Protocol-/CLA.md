**版本**: v1.0  
**生效日期**: 2026-07-15  
**项目**: LAAP (Living Agent Application Protocol)

---

感谢您向 LAAP 项目提交贡献！为了项目能够长期健康发展，并确保项目维护者有权将贡献用于社区版、商业版及未来可能的不同许可层级，请您在提交 Pull Request 之前阅读并同意本协议。

## 1. 定义

- **项目**: 指 LAAP (Living Agent Application Protocol) 及其所有子项目、衍生作品和关联仓库。
- **贡献者**: 指向项目提交代码、文档、设计、想法或其他任何形式贡献的自然人或法人。
- **贡献**: 指向项目提交的任何原创作品，包括但不限于源代码、文档、测试、设计、数据、反馈意见等。
- **项目维护者**: 指 Lorry 及其授权代表。

---

## 2. 授权范围

通过向项目提交贡献，您授予项目维护者一项**永久、全球、免费、不可撤销、可再许可**的权利，以：

1. 以任何方式使用、复制、修改、改编、翻译、展示、表演、分发您的贡献；
2. 将您的贡献纳入 LAAP 项目的社区版、商业版、云服务及其他衍生作品中；
3. 以任何许可协议（包括但不限于 Apache 2.0、Business Source License 1.1、商业授权协议或未来项目维护者认为合适的任何协议）再许可您的贡献；
4. 在不通知您或额外征得您同意的情况下，将您的贡献在不同许可层级之间迁移、合并或拆分；
5. 为维护 LAAP 项目的合法权益而在必要时行使上述权利。

上述许可不影响您对自身贡献的原始版权所有权。

## 5. 协议签署方式

### 方式一：Pull Request 评论（推荐）

在您首次提交的 Pull Request 中评论以下语句，即视为同意本协议：

```

```

如需正式签署纸质或电子版本，请联系项目维护者 Lorry。

## 7. 分层许可与再许可权

LAAP 项目采用**分层许可策略**，不同模块可能分别适用以下许可：

- **CC BY-SA 4.0**: 论文、理论文档与科学插图
- **Business Source License 1.1 (BSL 1.1)**: 核心认知引擎（`laap/`、`aris_brain/`），2030-07-15 后自动转为 Apache 2.0
- **商业授权协议**: Rust PSI Core（`core/`）、企业功能、闭源插件及云服务

您理解并同意：

1. 项目维护者有权将您的贡献用于上述任何层级，无需向您支付额外费用；
2. 项目维护者有权决定将您的贡献纳入社区版、商业版、论文或任何其他衍生作品；
3. 项目维护者有权在无需再次征得您同意的情况下，将您的贡献从一种许可切换为另一种许可，包括但不限于从 Apache 2.0 切换为 BSL 1.1 或商业授权；
4. 您的贡献被纳入商业版或闭源层级，并不赋予您商业版的任何特殊权利、收益权或许可。
