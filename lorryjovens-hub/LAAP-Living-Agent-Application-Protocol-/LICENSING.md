## 2. 各层级详细说明

### 层级 1：理论与论文 — CC BY-SA 4.0

- **覆盖范围**：
  - `docs/` 中理论规范、架构论文、设计文档
  - `papers/` 中学术论文（含中英文版本）
  - 架构图与科学插图（除非另有声明）
- **许可条款**：
  - 可自由复制、传播、修改
  - 必须保留原作者署名
  - 衍生作品必须以相同方式（CC BY-SA 4.0 或兼容协议）共享

### 层级 2：核心引擎 — BSL 1.1

- **覆盖范围**：
  - `laap/` 目录下的核心 Python 包（Agent 生命周期、认知引擎、协议、工具、网关等）
  - `aris_brain/` 目录下的 Aris 认知引擎实现
  - 与上述模块直接耦合的启动器、桥接器与工具脚本
- **许可条款**：
  - 源码公开、可阅读、可修改
  - **非生产环境可自由使用**
  - **生产环境使用需获得商业授权**
  - 2030-07-15 自动转为 Apache License 2.0
- **许可证文件**：根目录 `LICENSE`

### 层级 3：Rust 原生 PSI Core — 商业授权

- **覆盖范围**：
  - `core/` 目录下的 Rust 高性能引擎
  - 未来 `rust_core/` 编译后的二进制文件
- **许可条款**：
  - 仅提供闭源二进制或商业授权源码
  - 不允许反向工程、反编译
- **授权文件**：`COMMERCIAL_LICENSE.md`

### 层级 4：企业功能 — 商业授权

- **覆盖范围**：
  - 闭源插件、云同步、联邦学习、高级物种库
  - 私有化部署增强包
- **许可条款**：
  - 受独立商业授权协议约束
  - 未经授权不得使用、修改、分发
- **授权文件**：`COMMERCIAL_LICENSE.md`

## 3. 文件级许可判定规则

如果单个文件头部包含许可声明，以文件头部声明为准；否则按以下规则判定：

| 文件路径前缀 | 默认许可证 |
|---|---|
| `docs/` 中的论文/理论文档 | CC BY-SA 4.0 |
| `papers/` | CC BY-SA 4.0 |
| `laap/` | BSL 1.1 |
| `aris_brain/` | BSL 1.1 |
| `core/` | 商业授权 |
| `tests/` | 与对应被测模块保持一致 |
| 根目录 README、LICENSING.md、CLA.md 等 | 文本内容按知识共享原则使用，具体以本文件为准 |

---

## 4. 生产环境使用判定

BSL 1.1 下的“生产环境使用”包括但不限于：

- 将被许可作品用于向外部用户提供服务（SaaS、API、托管服务）
- 将被许可作品嵌入面向客户的产品或解决方案
- 在企业内部生产系统中长期运行并支撑核心业务

以下行为通常视为非生产使用：

- 本地开发、调试、学习、研究
- 运行自动化测试
- 在非公开沙箱中验证功能

如有疑问，请联系项目维护者确认。
