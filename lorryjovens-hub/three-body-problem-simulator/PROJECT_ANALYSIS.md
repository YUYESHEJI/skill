# 📋 项目分析与介绍页面设计报告

## 项目概述

**三体问题模拟器**是一个高性能的交互式 Web 应用，用于实时可视化三个天体在万有引力作用下的复杂运动。

### 核心技术特性
- ✅ RK4（四阶龙格-库塔法）精确数值积分
- ✅ WebGL 3D 实时渲染（Three.js）
- ✅ Web Worker 后台计算（百万级粒子）
- ✅ 多相机模式（自由、跟踪、电影级）
- ✅ 预设场景库（Figure-8、双星系统、自定义）

## 🎨 介绍页面设计方案

### 1. 设计哲学

**核心主题**：宇宙科幻极简 (Cosmic Sci-Fi Minimal)

这个主题的选择是由项目的本质驱动的：
- 项目处理的是**天体物理学**的复杂问题
- 涉及**3D 太空可视化**
- 代表**高科技**和**精确计算**

### 2. 色彩方案

```
Primary Colors:
  深黑色 (#0a0e27) - 主背景
  暗蓝灰 (#1a1a3e) - 次背景
  
Accent Colors:
  霓虹青 (#06b6d4) - 主强调色
  紫色 (#a78bfa) - 次强调色
  亮绿 (#00ff66) - 高亮
  
Supporting:
  黄色 (#facc15) - 信息
  柔红 (#f87171) - 警告/强调

理由：
- 青色/紫色 → 科技感与创新
- 深黑色 → 专业、高端
- 霓虹色 → 活力、未来感
```

### 3. 排版系统

```
Display Font: 
  现代加粗字体（通过Tailwind font-bold）
  用于标题和大型文本
  给予强烈的视觉占主导地位

Body Font:
  系统字体（Tailwind默认）
  清晰可读的正文
  优化网络性能
```

### 4. 动画策略

```
关键运动原则：
1. 入场动画：淡入 + 缩放 (opacity + scale)
2. 滚动动画：whileInView 触发的分层动画
3. 悬停效果：边框/背景颜色变化 + 阴影
4. 持续动画：呼吸效果（不打扰用户）
5. 平滑过渡：duration 0.3-0.6s

效果关键帧：
- 页面加载：星空背景粒子连续运动
- 英雄部分：光晕呼吸效果 + 下滑指示
- 特性卡片：列表淡入 + 边框悬停动画
- 预设场景：小球上下浮动
```

## 🎯 设计原则应用

### 1. 视觉层次
```
最高优先级：
  · 英雄部分标题
  · 行动召唤按钮
  · 核心特性标题

高优先级：
  · 子标题和描述
  · 特性卡片标题
  · 技术栈标签

中优先级：
  · 详细说明文字
  · 卡片内容

低优先级：
  · 页脚信息
```

### 2. 负空间利用
- 大段落之间宽松的行距
- 卡片周围的空间
- 顶部/底部的安全边距
- 创造呼吸感和精致感

### 3. 对比度原则
- 深色背景 + 亮色文字（WCAG AAA）
- 高色度霓虹色作为强调
- 柔和中间色用于次要元素

### 4. 微交互设计
```
悬停变化：
  边框：半透明 → 完整不透明
  背景：浅色 → 更亮
  阴影：无 → 柔和发光
  
焦点状态：
  用于键盘导航
  清晰可见的焦点环
```

## 🛠️ 技术实现细节

### Canvas 粒子背景
```typescript
// 特点：
// 1. 自适应分辨率
// 2. 使用 requestAnimationFrame 优化
// 3. 闪烁效果用正弦波实现
// 4. 粒子环绕屏幕边界
// 5. 渐变背景加强深度感
```

### Motion 动画库
```typescript
// 优点：
// - GPU 加速（使用 transform）
// - 高性能（不会触发重排）
// - 声明式 API（直观易用）
// - 支持 whileInView（滚动触发）

// 常用配置：
initial={{ opacity: 0, y: 20 }}    // 初始状态
whileInView={{ opacity: 1, y: 0 }}  // 可见时
transition={{                       // 动画配置
  delay: index * 0.1,             // 列表错开延迟
  duration: 0.6,                  // 持续时间
  type: "spring"                  // 弹簧效果
}}
viewport={{ once: true }}          // 只在进入时动画一次
```

### Tailwind CSS 响应式

```typescript
// 响应式类名
className="
  grid 
  md:grid-cols-2      // 平板: 2列
  lg:grid-cols-3      // 桌面: 3列
  gap-6               // 一致的间距
"
```

## 📊 性能优化

### 1. Canvas 优化
- 粒子数量适中（100个）以保证 60fps
- 使用 transform 改变粒子位置（GPU加速）
- requestAnimationFrame 节流

### 2. CSS 优化
- CSS 变量用于一致的颜色方案
- 使用 GPU 加速的属性（opacity, transform）
- 避免 JavaScript 触发重排

### 3. 动画优化
- Motion 库使用 transform（不触发重排）
- 合理的延迟避免一次性运行所有动画
- whileInView 只在需要时运行

## ✨ 设计特色（避免 AI 陷阱）

### ✅ 做正确的事
- 定制 CSS 变量色彩方案（不是默认主题）
- Canvas 自定义背景（不是 stock 图片）
- 考虑周到的排版（不是默认字体）
- 主题化的布局（不是标准卡片网格）
- 根据项目定制的美学（不是通用模板）

### ❌ 避免的事
- ❌ 不使用 Inter 或 Roboto（通用字体）
- ❌ 不使用老套的紫色渐变
- ❌ 不使用标准的 "粉色 + 蓝色" 配色
- ❌ 不使用 stock 照片或默认图片
- ❌ 不使用完全对称的布局

## 📱 响应式断点

```
移动端 (< 640px):
  - 单列布局
  - 较小的字体 (text-3xl → text-4xl)
  - 较小的边距
  - 按钮尺寸优化

平板 (640px - 1024px):
  - 2-3 列网格
  - 中等字体
  - 平衡的间距

桌面 (> 1024px):
  - 完整的 3-4 列网格
  - 全部动画效果启用
  - 最佳视觉体验
```
